# card-news-creator

컨텍스트(주제, 내용)를 입력받아 카드뉴스 HTML 파일과 PNG 이미지를 자동 생성하는 Claude Code 플러그인.

## 특징

- **8종 템플릿 내장**: 남색/빨강/파랑/회색/흑백 계열 디자인
- **슬라이드 자동 구성**: 목적·분위기에 맞는 템플릿 자동 선택
- **HTML → PNG 변환**: Playwright MCP를 이용한 고해상도 이미지 추출 (1080×1440px)
- **현재 작업 디렉토리 출력**: `./output/YYYY-MM-DD-주제/` 형태로 저장

## 설치

```bash
# 마켓플레이스에서 설치
/plugin install card-news-creator@ky-marketplace

# 또는 즉시 테스트 (설치 없이)
claude --plugin-dir ./card-news-creator
```

## 사용법

```
/card-news-create 우리 팀 4월 온보딩 안내 자료 만들어줘
/card-news-create 신제품 런칭 마케팅 카드뉴스 (빨강 템플릿으로)
/card-news-create [긴 컨텍스트 내용 붙여넣기]
```

## 템플릿 목록

| 템플릿 | 슬라이드 수 | 용도 |
|--------|-----------|------|
| 남색_깔끔_홍보_안내 | 9 | 기업/정책 홍보, 프로페셔널 |
| 빨강_깔끔_마케팅_콘텐츠_안내 | 8 | 마케팅, 캠페인 |
| 파랑_깔끔_뉴스_홍보 | 5 | 뉴스레터, 짧은 소식 |
| 파랑_심플_공지사항_안내 | 5 | 공지사항, 월간 소식 |
| 파랑_심플_홍보_안내 | 9 | 일반 홍보, 다목적 |
| 파랑_회식_깔끔_표_위주 | 4 | 데이터/표 중심 |
| 회색_파랑_모던_홍보_안내 | 8 | 모던, 스타트업/기술 |
| 흑백_깔끔_온보딩_안내 | 7 | 온보딩, 미니멀 가이드 |
