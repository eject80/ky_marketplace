# Supanova-Design-Skill

Premium Korean landing page design system for Claude Code.

## Skills

| Skill | Description |
|-------|-------------|
| `supanova-design-engine` | Core design engine. Generates premium landing pages with configurable variance, motion intensity, and visual density settings. |
| `supanova-premium-aesthetic` | Aesthetic ruleset. Defines fonts, spacing, card architecture, motion choreography, and anti-pattern blocks for $150k agency-quality output. |
| `supanova-redesign-engine` | Redesign auditor. Upgrades existing landing pages by diagnosing and fixing generic AI design patterns. |
| `supanova-full-output` | Output enforcer. Prevents truncation — ensures every landing page is delivered complete with zero placeholder patterns. |

## Usage

Once installed, use any skill by referencing its name in a prompt:

```
랜딩페이지 만들어줘 — AI 생산성 도구, 다크 테마
```

```
이 HTML 파일을 Supanova 기준으로 리디자인해줘
```

## Installation

```
/plugin install Supanova-Design-Skill@local-marketplace
```

Or test without installing:

```bash
claude --plugin-dir ./Supanova-Design-Skill
```
