시작하기

파일 구조를 이해하고 첫 번째 PPT를 만들어 봅니다

발표자 노트

  • 섹션 구분 슬라이드입니다. 챕터 전환 시 사용합니다.
  • section-bg-num: 우측 반투명 큰 숫자 (장식용)

파일 3개로 구성된 엔진

  • presentation.css — 엔진 스타일 전체. 수정 금지. 모든 컴포넌트 CSS 포함.
  • presentation.js — 네비게이션·전환·Step 재생 로직. 수정 금지. window.Presentation API 노출.
  • index.html — ★ 이 파일만 수정. 슬라이드 내용을 추가하고, 필요하면 CSS 변수로 색상을 바꾸세요.
  • 새 PPT 시작: template/ 폴더 전체 복사 → index.html 수정 → 완성!

발표자 노트

  • 슬라이드 진입 시 항목이 350ms 간격으로 순차 표시됩니다.
  • 이것이 data-step 자동 재생 기능입니다.

Part 02

슬라이드 작성법

기본 구조와 꼭 알아야 할 핵심 기능

발표자 노트

  • 슬라이드 HTML 구조와 핵심 클래스를 설명합니다.

슬라이드 기본 구조

<!-- 슬라이드 하나 = <section> 하나 -->
<section class="slide [추가클래스]"
         id="slide-N"
         data-slide-index="N-1"
         data-transition="fade|slide|zoom"
         role="group" aria-roledescription="슬라이드">
  <div class="slide__content">
    <!-- 여기에 내용 작성 -->
  </div>
  <aside class="slide__notes">
    <!-- 발표자 노트 (청중에게 보이지 않음) -->
  </aside>
</section>

data-slide-index는 0부터 시작하는 정수. 슬라이드 추가 시 순서대로 유지하세요.

발표자 노트

  • 코드 블록도 .step 클래스를 붙이면 자동 재생됩니다.
  • data-transition: fade(기본) / slide / zoom 중 선택.

두 가지 핵심 기능

① Step 자동 재생

<!-- data-step 순서대로 표시 -->
<li class="step"
     data-step="1">
  첫 번째 항목
</li>
<li class="step"
     data-step="2">
  두 번째 항목
</li>

② 핵심 단어 강조 .hl

<!-- 제목·본문 모두 사용 가능 -->
<h2>
  데이터 <span
    class="hl">
    분석
  </span> 결과
</h2>

<!-- --primary 색상으로 표시 -->
<!-- 테마 전환 시 자동 변경 -->

발표자 노트

  • .step은 li, div, p, pre, span 등 어떤 요소에도 적용 가능합니다.
  • .hl은 --primary CSS 변수를 사용해 테마 전환 시 자동으로 색이 바뀝니다.

커스터마이즈

색상·테마·JavaScript API로 PPT를 나만의 것으로

발표자 노트

  • CSS 변수로 색상을 바꾸고, JS API로 외부 연동도 가능합니다.

색상 커스터마이즈

<!-- index.html <head> 안에 추가 -->
<style>
  :root {
    --slide-bg:    linear-gradient(135deg, #0f172a 0%, #1e3a5f 100%);
    --slide-color: #f0f0f0;
    --primary:     #60a5fa;  /* 강조색: .hl, 진행바, 버튼 */
    --accent:      #fb923c;  /* 보조 강조색 */
  }
  [data-theme="light"] {
    --slide-bg:    #f4f6f9;
    --slide-color: #1a1a1a;
    --primary:     #0057b7;
  }
</style>

4개 변수만 바꾸면 전체 색상 테마가 바뀝니다. presentation.css는 건드리지 않아도 됩니다.

발표자 노트

  • index.html의 <head> 안에 <style> 태그를 추가하면 됩니다.
  • --primary 변수를 바꾸면 .hl, 진행 바, 버튼 등 모든 강조 요소가 함께 바뀝니다.

키보드 단축키 & JS API

키보드 단축키

  • → / Space — 다음 슬라이드
  • ← — 이전 슬라이드
  • Home / End — 처음 / 마지막
  • F — 전체화면 토글
  • N — 발표자 노트 토글
  • D — 다크/라이트 전환
  • ? — 단축키 도움말

window.Presentation API

  • .next() — 다음 슬라이드
  • .prev() — 이전 슬라이드
  • .goTo(n) — n번으로 이동 (0-based)
  • .first() / .last()
  • .toggleNotes() — 노트 토글
  • .toggleTheme() — 테마 전환
  • .getState() — 현재 상태 반환

발표자 노트

  • window.Presentation API로 외부 버튼이나 리모컨 연동이 가능합니다.
  • ? 키를 누르면 화면에 단축키 도움말이 표시됩니다.
